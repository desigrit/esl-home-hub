Add a system to RonHub

Each system has a name, a dedicated page, and a status adapter. The overview and navigation use the same system registry.

1. Register the system

Add its ID, name, host, icon, route, and repository in ronhub/registry.py.

2. Report meaningful health

Add an adapter in ronhub/service.py. Return a status, a useful summary, the observation time, and any metrics or next run. Keep connection failures, missing evidence, paused work, and job failures distinct.

3. Add its management page

Add the page renderer to ronhub/static/hub.js. Use the shared navigation, forms, status labels, and activity components. Register only the actions the integration needs.

4. Verify the lifecycle

Test healthy, failed, offline, paused, and stale states. Test that credentials never enter the response. Deploy the new module with a backup, then verify the live overview and project page.

Status contract

{
  "status": "healthy",
  "summary": "Latest update completed",
  "checked_at": "ISO 8601 timestamp",
  "next_run": "ISO 8601 timestamp or null",
  "metrics": [{"label": "Pending jobs", "value": 0}]
}

Accepted states: healthy, running, paused, sleeping, warning, error, offline, and unknown. External status reports need authentication and a freshness limit.
